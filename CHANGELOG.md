# Changelog

| Version | Date | Changes |
|---|---|---|
| **1.5.0** | 2026-11-26 | Mobile layout for phones and the installed app: a slim header, a tab bar at the bottom (Cypher console, Data & storage and About under More), a Recommendations / Graph switch on Recommend so the neighbourhood graph fills the screen, a sommelier chat that fills the screen with the key settings folded away once a key is set, and a path graph that fills the space under the pickers. The desktop layout is unchanged. |
| **1.4.0** | 2026-11-26 | Installable as a progressive web app: web app manifest, home-screen icons (192, 512 and maskable 512 px) and a service worker, so the site can be added to a phone's home screen and runs full-screen. After one online visit it also works offline; the sommelier and the Wikipedia re-import still need a connection. |
| **1.3.2** | 2026-11-24 | Saved relate store committed as `data/beergraph.relate` (the full graph plus a `demo` drinker with four ratings), with `data/README.md` on where the live OPFS store lives, how to load the file and its format. New README sections "How it uses Relate" (directory mode on OPFS, and why) and "Persistent store". The Devpost draft answers the Relate mode and store path questions. |
| **1.3.1** | 2026-11-24 | Mondrian favicon (a glass of beer in an ink grid with red and blue tiles) and a matching home-screen icon for iPhone and iPad. The Devpost submission draft is now in `docs/`. |
| **1.3.0** | 2026-11-24 | Backup and restore on the Data & storage tab: download relate's own OPFS store (graph, ratings and sommelier memory) as one gzipped `.relate` file, and upload it again in another browser or after clearing site data. Uploads are checked, and the previous graph is put back if relate cannot open the file. The engine line now shows relate's version from the build. |
| **1.2.0** | 2026-11-23 | New About tab: the story behind the BeerGraph, the Monki Gras 2013 talk (embedded from YouTube's no-cookie domain), links to all the BeerGraph blog articles from 2013 to 2021 and the GraphGist, and links to the author's website, LinkedIn and this repository. |
| **1.1.1** | 2026-11-23 | Relate by Neo4j Hackathon compliance: README statement of the relate capabilities, third-party tools and AI tools used, disclosure of earlier work, fuller setup instructions and a walkthrough for judges; footer note that the project is independent and not endorsed by Neo4j, with a link to the source. |
| **1.1.0** | 2026-11-23 | Recommend page redesign: graph walk and vector neighbours are now sub-tabs on the left, with the neighbourhood graph always visible on the right (graph first on phones). The graph highlights the top picks of the active list and draws vector similarity as dashed links. Fixed the graph canvas growing past its box and the tab colour markers all showing red. |
| **1.0.0** | 2026-11-23 | First public release. Belgian beer graph from the Dutch Wikipedia list (2,321 beers) running on relate (WASM) in a Web Worker with OPFS persistence. Graph-walk and vector recommendations, taste memory per drinker, "drinkers like you", path finder, Cypher console, live Wikipedia re-import, optional Claude sommelier agent (Haiku 5.5 by default, visitor's own API key), Mondrian theme, GitHub Pages deploy, Apache-2.0 license. |
